# vibecoding 远程运维解决方案设计方案

## 一、项目背景
本方案为LinkAgent网关提供远程运维全栈能力，解决多Agent管理、多Cursor实例负载均衡、内网服务暴露、远程文件/进程管理等需求，实现全流程可视化运维。

## 二、整体架构
采用分层插件化架构，完全兼容现有LinkAgent体系：

```
┌─────────────────┐    ┌─────────────────┐
│   终端用户      │    │  内网客户端     │
│ (浏览器/Cursor) │    │ (frpc/Agent)    │
└─────────┬───────┘    └────────┬────────┘
          │                     │
┌─────────▼─────────────────────▼────────┐
│           Nginx反向代理 :80            │
│  ├─ / → LinkAgent Web UI :8787         │
│  ├─ /v1 → 网关API :8787                │
│  └─ /frps → FRPS管理后台 :7500         │
└─────────────────┬──────────────────────┘
                    │
┌─────────────────▼──────────────────────┐
│       LinkAgent Gateway 网关层         │
│  ├─ 多Cursor实例负载均衡调度           │
│  ├─ /api/remote/* 远程运维API          │
│  ├─ PM进程管理器（nginx/frps/agents）  │
│  └─ 权限鉴权中心                        │
└─────────────────┬──────────────────────┘
                    │
┌─────────────────▼──────────────────────┐
│          vibecoding 服务层             │
│  ├─ Agent管理模块                      │
│  ├─ 文件管理插件                        │
│  ├─ 进程/服务管理插件                   │
│  └─ 远程桌面插件（开发中）              │
└─────────────────┬──────────────────────┘
                    │
┌─────────────────▼──────────────────────┐
│            基础设施层                  │
│  ├─ FRPS内网穿透服务端 :7000/8080      │
│  ├─ 3个Cursor实例（独立工作目录）       │
│  ├─ 多Agent实例（pi/opencode等）       │
│  └─ 持久化存储（YAML配置/用户数据）     │
└────────────────────────────────────────┘
```

## 三、核心功能模块

### 1. 多Cursor实例自动负载均衡
- **配置**：3个独立Cursor实例，ID分别为`cursor`、`cursor-2`、`cursor-3`
- **隔离**：每个实例独立工作目录，独立配置文件，无资源冲突
- **调度**：网关层自动分配请求到空闲实例，支持平滑扩容
- **Token**：统一使用用户提供的Cursor API Key：`crsr_9dbe93e3247e6dd8223048dd515477aabb41a7dedeb63785a014cbeb98ddcf3f`

### 2. 远程运维能力（vibecoding）
- **文件管理**：远程浏览、读写、上传下载文件，支持目录操作
- **进程管理**：远程执行命令、查看进程列表、启停服务、监控系统资源
- **远程桌面**：（开发中）支持VNC/RDP协议远程访问桌面环境
- **API入口**：`/api/remote/*` 统一远程接口前缀

### 3. 内网穿透服务（FRP）
- **服务端部署**：frps v0.60.0，绑定端口7000
- **HTTP代理**：vhost端口8080，支持多域名映射内网HTTP服务
- **Dashboard**：通过Nginx反向代理到`/frps/`路径，账号`admin`，密码`linkagent@2024`
- **认证Token**：`linkagent_frp_token_2024`，所有客户端连接需携带此Token

### 4. Nginx反向代理
- **统一入口**：80端口对外提供所有服务
- **路径路由**：
  - `/` → LinkAgent Web管理后台
  - `/v1` → OpenAI兼容API接口
  - `/api/*` → 管理后台API
  - `/frps/*` → FRPS管理后台
- **WebSocket支持**：已配置升级头，支持SSE流式响应、WebSocket通信

### 5. Web UI新增功能
- **IDE菜单**：在「我的」分组下新增「在线IDE」入口，对接远程Agent运维能力
- **插件化扩展**：预留文件浏览器、代码编辑器、终端三个Tab位，后续逐步完善功能

## 五、部署说明
### 部署拓扑
单云服务器部署，无需额外硬件资源，所有服务运行在同一实例：
- 公网IP：`216.19.4.113`
- 开放端口：`80`(HTTP)、`7000`(FRP服务端)

### 部署命令
```bash

# 启动开发环境

# 前端构建
pnpm --filter @linkagent/web build

# 后端测试
pnpm --filter @linkagent/backend test
```
